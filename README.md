# OrangeHRM Selenium Automation Framework

## Project Overview
This is a Selenium Java Automation Framework developed for automating the OrangeHRM web application.

## Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Extent Reports

## Features
- Page Object Model (POM)
- Cross-browser support
- Screenshot capture on failure
- TestNG execution
- Data-driven testing
- Maven project structure
- Extent Reports

## Project Structure
```
src/
 ├── main/
 └── test/
TestData/
pom.xml
testng.xml
```

## How to Run
1. Clone the repository.
2. Import as a Maven project in Eclipse.
3. Update dependencies using Maven.
4. Run `testng.xml`.
